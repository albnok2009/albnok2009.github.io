# بوابة محمد القحطاني التعليمية

نسخة أولية ثابتة للبوابة التعليمية، متوافقة مع GitHub Pages.

## النشر
1. أنشئ مستودعًا عامًا باسم `albnok2009.github.io` في حساب GitHub `albnok2009` (إذا كان هذا اسم الحساب الفعلي).
2. ارفع ملف `index.html` إلى جذر المستودع.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)` واحفظ.
4. انتظر النشر وافتح `https://albnok2009.github.io`.

**تنبيه:** بطاقات البرامج لا تحتوي بعد على روابط تشغيل فعلية، لتجنب عرض روابط غير مؤكدة. أضف روابط البرامج بعد التحقق من نشرها.
